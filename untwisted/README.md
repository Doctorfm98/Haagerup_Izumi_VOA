# Untwisted cyclic Haagerup–Izumi centers

**Vertex operator algebra realizations of untwisted cyclic Haagerup–Izumi centers**  
David E. Evans and Andrew Riesen  
Current working manuscript · 23 October 2026

This is the authors’ current working manuscript. The authors intend to continue refining the arguments, notation, organization, and exposition to make the work easier for human readers to understand and verify. Mathematical feedback and corrections are welcome.

- [Read the manuscript](Untwisted_HI_Working_Manuscript.pdf).
- [Read the self-contained LaTeX source](Untwisted_HI_Working_Manuscript.tex).

The source includes the bibliography, AI disclosure, and the complete symbolic frame calculation in Appendix I. No supplementary files are required to compile or read the manuscript. The Python code in Appendix I can be run separately with Python 3 and SymPy; see the [build instructions](../BUILDING.md).

Run `make untwisted` from the repository root to compile into `build/untwisted/`; see [build instructions](../BUILDING.md). Exact file hashes are recorded in [SHA256SUMS](../SHA256SUMS).
